# ¿Qué es un lápiz?

- Herramienta de escritura y dibujo
- Compuesta por una mina y una madera o cuerpo
- Disponible en diferentes durezas y materiales
- Usada en arte, ingeniería, escuela y diseño

---

# Lápices de grafito

- Los más comunes para escritura y dibujo técnico
- Dureza indicada por números y letras (H, B, HB)
- Ejemplos:
  - 9H: muy duro, líneas claras
  - HB: estándar
  - 9B: muy blando, líneas oscuras

---

# Lápices de colores

- Contienen pigmentos mezclados con aglutinantes
- Usados para ilustración, coloreado y bocetos
- Vienen en una amplia gama de tonos y texturas
- Ideal para trabajos expresivos y creativos

---

# Lápices mecánicos

- Mina recargable dentro de un cuerpo reutilizable
- Diámetros comunes: 0.5 mm, 0.7 mm, 0.9 mm
- Buen control para escritura precisa y dibujo técnico
- No requieren afilado

---

# Lápices de carbón

- Mina de carbón vegetal o comprimido
- Trazo profundo y mate, ideal para sombreado rápido
- Se difumina fácilmente para crear transiciones suaves
- Ideal para bocetos artísticos y estudios de figura

---

# Lápices acuarelables

- Combina lápiz de color con pigmento soluble en agua
- Permite efectos de acuarela cuando se humedece
- Excelente para ilustraciones mixtas
- Disponible en versiones suaves y duras

---

# Accesorios y uso

- Goma para borrar
- Sacapuntas para lápices tradicionales
- Portaminas para lápices mecánicos
- Papel de calidad y difuminos para sombreado

---

# Consejos para elegir lápices

- Para dibujo técnico: H, HB, F
- Para bocetos artísticos: 2B a 6B
- Para retratos: mezcla de durezas y carboncillos
- Para coloreado: lápices de ceras o acuarelables

---

# Resumen

- Grafito: versátil y estándar
- Colores: ideales para creatividad
- Mecánicos: precisos y limpios
- Carbón: expresivo y profundo
- Acuarelables: mezcla artística y técnica
